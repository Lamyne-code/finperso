# FinPerso

Application personnelle de suivi de budget (dépenses, revenus, charges à venir, projets), installable sur téléphone.

Adresse une fois publiée : `https://<ton-nom-github>.github.io/finperso/`

Les données restent sur l'appareil. Sauvegarde : Réglages > Sauvegarde > Exporter une sauvegarde.
